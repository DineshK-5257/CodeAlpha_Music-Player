About MelodyHub

MelodyHub is a modern, responsive music player application designed and developed for CodeAlpha Internship Task 4.

  • ✨ Dark glassmorphism neon interface
  • 🎵 Dynamic HTML5 Audio engine with Web Audio synthesizer fallback
  • 🔍 Live song, artist, & genre search filtering
  • ♡ Favorite songs list & local storage persistence
  • ◷ Recently Played track history
  • 🎛️ Full controls: Play/Pause, Seek, Volume/Mute, Shuffle, Repeat
  • ⌨️ Keyboard shortcut navigation
  • 📱 Fully responsive desktop, tablet & mobile layout
